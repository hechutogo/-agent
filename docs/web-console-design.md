# DeepSeek 网页控制台

用户已确认：嵌入持续刷新的仿真 RGB 相机画面，连续自然语言控制，展示五段动作和结果，直接实现。

## 设计

沿用 `CloudAgent`、`PickPlace`、`Simulation`；FastAPI 提供单机网页与 JSON API。
一个专用线程拥有仿真和 Agent，串行执行命令；HTTP 线程只读取快照，避免 SAPIEN 跨线程访问。
浏览器轮询状态与相机帧，刷新页面后恢复当前会话。所有物理判断仍只基于 RGB-D 和本体状态。
工具结果作为成功依据，执行中拒绝第二条命令，重置创建新场景和新对话。

DeepSeek 使用本机凭据，写入被 git 忽略的 `.env`，权限 0600。
启用 OpenAI 原生工具调用，修复 Qwen-Agent 0.0.34 的工具结果关联字段。
云视觉独立配置，禁止把 DeepSeek 密钥传给其他供应商。没有云视觉配置时明确显示缺失；
可由用户在网页选择 OpenCV RGB-D 感知演示，仍由真实 DeepSeek 选择工具，但不算云视觉验收。

## 实施与验证

1. 新增原生工具消息兼容测试，先失败，再修复 DeepSeek 适配；实际调用验证密钥和工具返回。

3. 增加仿真帧回调和阶段回调，网页 canvas 呈现传感器帧。
4. 实现响应式 HTML/CSS/JS 控制台，提供指令输入、历史、五段进度、重置和模式提示。
5. 运行单元/物理回归、真实 API 验证、浏览器交互；记录实际验证边界，启动本地服务。
