# 抓取、放置与视觉检查排障

## 先区分故障阶段

1. 查执行产物的 `failed_index`，明确失败发生在下降、闭爪、抬升、搬运、
   放置下降还是后撤；不要把所有 `grip_failed` 都解释成夹持力不足。
2. 核对闭爪是否已经派发。闭爪前观测失败不应创建候选；闭爪部分执行后
   异常必须保留候选，不得立即张爪复位。
3. 分开判断空爪、持物、目标关系。物体脱离夹爪但倾斜在支撑边缘时，
   空爪可以确认，放置目标依旧失败；应允许基于新观测纠正。
4. 查看 `visual-evidence` 的采样数。暂时不可见先局部稳定观测，
   持续缺失不能作为成功证据，也不能靠增加任务重试预算解决。

## 已验证根因

### 下降遮挡了闭爪前的基线

历史任务 `20260922-143053-b79a`，B 的完整区域为 246 像素。机械臂下降后，
其中 143 像素被灰色末端遮住，前景深度前移 35～56 mm，留下 40 和 62 像素
两块蓝色碎片。s12、s13、s17 的图像与深度相同，再次读取不能恢复可见性。

保留歧义拒绝：不能选最大碎片或跨夹爪补洞伪造中心。修复是把抓取基线移至
当前执行开始、下降之前，并限定为本次目标；不将失败准备伪装成闭爪。

### 搬运转向改变了抓取偏移

真实 seed 7，B→A 的传感器诊断：

| 时刻 | TCP−物体的 X/Y 偏移 |
|---|---|
| 源位置抬升后 | −5.8 / −7.6 mm |
| 目的位置悬停后 | +5.8 / −2.2 mm |

手腕转向后继续使用源位置偏移，使物体中心偏离目标约 11.5 mm。24 mm
物块的支撑余量很小，释放后滑到边缘，不能通过稳定堆叠检查。

优化版在目的位置下降前重新读取 RGB-D 和本体状态，确认持物、更新偏移，
再验证剩余完整路径。自研 `CarryTo` 同步更新持物偏移供放置原子使用。
该问题由会改变实际物体偏移的传感器测试复现；原失败物理用例经修复通过。
精确放置仅对超过 3 mm 的偏移变化纠偏，防止微小测量噪声使边界路径失效；
容器则按实测内壁余量决定纠偏需求，避免不必要调整改变盒内落点和取回路径。

### 释放和放稳被混为同一个状态

夹爪已实际张开、候选物体离开 TCP 邻域时，即便物体倾斜、目标关系未满足，
也可以确认已脱离。清除持物候选不写入“已放置”，目标仍需连续两次视觉确认。
物体还在夹爪附近且支撑不明时继续保持未知状态。

## 共同边界

- 视觉目标验证最多三帧，连续两次正证据才通过；相邻采样保持八个物理步。
- 桌面接触使用实测底部，间隙为 `-3 mm ≤ gap < 4 mm`。
- 堆叠中心至少内缩 2 mm、接触面积至少 50%、高度间隙为 `-3～8 mm`。
- 盒内关系与盒底支撑分开；只在盒壁明确遮挡时允许固定物块高度辅助判断。
- TCP 误差不放宽到 8 mm 以上；运动前检查整段 8 mm 插值 IK。
- 自研候选解除使用同帧视觉位置和 TCP 的充分分离证据；未知候选禁止盲目张爪。
- 搬运失败或目的地持物测量失败会使旧偏移失效，必须重新测量才能放置。
- 模型只处理对象 ID；不使用仿真 actor pose、奖励或接触真值做决定。
